# Подробная история изменений TS_switcher

Все версии с техническими подробностями. Пользовательская история всех версий — в [CHANGELOG.md](CHANGELOG.md), последний релиз — в [README](README.md#история-изменений). Описания выпусков на GitHub берутся из CHANGELOG.md.

Каждая версия описывается целиком относительно предыдущего стабильного релиза. Промежуточные beta-сборки входят в общий раздел своей версии.

### Версия 1.0.0

Готовится к выпуску. Изменения относительно версии 0.3.5.

**Поддерживаемые сайты и ссылки**

- На ТС поддерживаются оба варианта адреса турнира: `/tournament/:id` и `/tournaments/:id`; кнопки рейтингов доступны для обоих. Переходы между зеркалами сохраняют исходный вариант пути.

- Добавлены зеркало `rating.pecheny.ru` и рейтинги `rating.chgk.fun`, `chgk.quest`, `elo-chgk.uk`: всего восемь поддерживаемых сайтов.
- Правила сайтов и преобразования URL собраны в `sites.js`. Между рейтингами используются общие типы страниц: игрок, команда, турнир и главная.
- Кнопки перехода и копирования показываются только для поддерживаемого соответствия страниц. Между зеркалами ТС доступен переход с любым путём; перехода на главную вместо отсутствующей страницы нет.
- Ссылки между зеркалами ТС сохраняют подпути, параметры запроса и `#якорь`. Для рейтингов формируется канонический путь без параметров и подпутей исходного сайта.
- Копирование доступно для каждого поддерживаемого сайта, включая текущий.

**Настройки и автоматические переходы**

- Добавлена страница настроек: выбор предпочитаемого ТС, предложение другого зеркала при сетевой ошибке и отдельная видимость кнопок перехода и копирования для каждого сайта.
- Предпочитаемый ТС можно выбрать также в попапе. При включённой настройке ссылки на другие TS-хосты автоматически открываются на выбранном; по умолчанию настройка выключена.
- В Chromium переходы реализованы через `declarativeNetRequest`, в Firefox — через блокирующий `webRequest`.
- Ручной переход кнопкой расширения обходит автоматическое перенаправление один раз через `ts_switcher_direct=1`. Content script удаляет этот параметр, сохраняя остальной URL и `history.state`.
- `/login` и `/logout` на зеркалах исключены из автоматического перенаправления. После открытия `/login` оно приостановлено в этой вкладке до `/logout` или закрытия вкладки, в том числе при выходе через HTTP redirect.
- Если сайт отправляет на `rating.chgk.info/login`, расширение возвращает на предпочитаемое зеркало или последнее зеркало вкладки. В настройках есть прямые ссылки «Войти» для каждого TS-хоста.
- Изменения настроек сохраняются через единую очередь background. Открытые окна настроек получают обновления, сохраняя незавершённые изменения пользователя.

**Предложение другого зеркала при ошибке**

- Когда автоматическое перенаправление выключено и страница ТС не загружается из-за сетевой ошибки, попап предлагает открыть тот же URL на другом зеркале.
- В предложении участвуют только сайты с включёнными кнопками перехода. Подписи короткие (`.me`, `.kz`, `.ru`), полный хост доступен в подсказке.
- Отмена загрузки не считается недоступностью сайта. HTTP-ответы 4xx/5xx и бесконечная загрузка не запускают предложение.
- Сведения об ошибке привязаны к вкладке, очищаются после успешного перехода или закрытия; срок актуальности — пять минут.

**Интерфейс и работа браузера**

- Попап следует теме активной TS-вкладки (Classic, Oldschool, Catppuccin и тема для дальтоников в light/dark). На рейтингах используется палитра gg; режим gg берётся из вкладки, остальных рейтингов — из браузера/ОС.
- Добавлены независимые настройки режима ТС, семейства ТС, контрастности ТС и режима рейтингов. Все четыре темы используют обычные и контрастные палитры самого ТС. Автоматическая контрастность следует настройке сайта; ручной выбор имеет приоритет.
- Страница настроек использует те же палитры и параметры оформления, следует контексту сайта своего окна и обновляется без перезагрузки.
- Тема передаётся из content script только при открытом соединении с попапом или страницей настроек, без хранения состояния страницы и дополнительных разрешений.

- Кнопки копирования ссылок на ТС сохраняют палитру ТС и на сайтах рейтинга; обводка берётся из палитры темы (в светлой Classic — тёмная песочная).
- Кнопки копирования расположены в двух рядах: ТС и зеркала сверху, рейтинги снизу. Число колонок подстраивается под видимые кнопки, максимум — 4×2.
- У кнопок перехода и копирования есть подсказка с полной ссылкой; при нехватке места попап прокручивается.
- Попап обновляется по событиям вкладок и хранилища, без периодического опроса. Кнопки пересоздаются только при изменении состава или ссылок.
- Попап и настройки используют Noto Sans из themes.css. Шрифт с кириллицей и латиницей включён в расширение вместе с лицензией; внешних запросов нет.
- Состояние вкладок Chromium восстанавливается при перезапуске service worker. Firefox использует постоянный background и загружает настройки перед обработкой переходов.

**Сборка и проверки**

- Сборщик проверяет версии и ресурсы обоих браузеров, создаёт архивы во временном каталоге и сохраняет исходные манифесты и прежние архивы версий.
- Некорректные номера версий и понижение относительно исходных манифестов отклоняются. Выпуск под тегом другого коммита блокируется.
- Добавлены проверки URL, интерфейса, настроек, перенаправлений, авторизации, сетевых ошибок и сборки. Интеграционные сценарии выполняются в настоящих Chromium и Firefox с изолированными профилями и контролируемыми ответами сайтов.
- Проверки логики и сборки запускаются в CI до выпуска. Описания выпусков берутся из `CHANGELOG.md`; beta-сборки используют общий раздел своей версии.
