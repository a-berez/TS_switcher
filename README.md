# TS_switcher

Расширение для браузера: переключение вкладки между Турнирным сайтом, зеркалами и сайтом Рейтинга. Текущая версия — `1.1.1`. Текущее состояние и статус магазинов — `docs/status.md`, проверки — `tests/README.md`. Документы для агентов: `AGENTS.md`.

Расширение позволяет легко переключаться между [Турнирным сайтом](https://rating.chgk.info) и его зеркалами, а также сайтами рейтинга:
- [rating.pecheny.me](https://rating.pecheny.me)
- [rating.pecheny.kz](https://rating.pecheny.kz)
- [rating.pecheny.ru](https://rating.pecheny.ru)
- [rating.chgk.gg](https://rating.chgk.gg/)
- [rating.chgk.fun](https://rating.chgk.fun/)
- [chgk.quest](https://chgk.quest/)
- [elo-chgk.uk](https://elo-chgk.uk/)
- [a2.pecheny.me](https://a2.pecheny.me/)
- a2.pecheny.kz — зеркало A2, поддержка подготовлена до запуска
- a2.pecheny.ru — зеркало A2, поддержка подготовлена до запуска

## Возможности

- Переключение между Турнирным сайтом, зеркалами и семью хостами рейтингов с конвертацией URL
- Настраиваемый перехват: предпочитаемый хост ТС (info / .me / .kz / .ru) — все ссылки сразу ведут на выбранный домен
- Независимый предпочитаемый сайт A2 (.me / .kz / .ru) с сохранением полного адреса между зеркалами
- Предложение другого зеркала в попапе, если страница ТС не загрузилась (сетевая ошибка)
- Настройка видимости кнопок переключения и копирования для каждого сайта
- Копирование ссылки на любой из поддерживаемых сайтов с текущей страницы

## Установка

### Из магазинов расширений

- **Firefox**: [магазин расширений Firefox](https://addons.mozilla.org/ru/firefox/addon/ts_switcher/)
- **Chrome / Edge / Opera / Яндекс Браузер**: [интернет-магазин Chrome](https://chromewebstore.google.com/detail/tsswitcher/kbfllpfigjilnlfhkalpbjoigkfplblk)

### Установка вручную

#### Chrome / Edge / Opera / Яндекс Браузер

1. Перейдите в раздел [Releases](https://github.com/a-berez/TS_switcher/releases) или скачайте [TS_switcher-chromium.zip](https://github.com/a-berez/TS_switcher/releases/latest/download/TS_switcher-chromium.zip) (последняя версия)
2. Распакуйте архив
3. Откройте:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Opera: `opera://extensions/`
   - Яндекс Браузер: `browser://extensions/`
4. Включите "Режим разработчика" в правом верхнем углу
5. Нажмите "Загрузить распакованное расширение" и выберите распакованную папку

#### Firefox

1. Перейдите в раздел [Releases](https://github.com/a-berez/TS_switcher/releases) или скачайте [TS_switcher-firefox.zip](https://github.com/a-berez/TS_switcher/releases/latest/download/TS_switcher-firefox.zip) (последняя версия)
2. Откройте Firefox и перейдите в `about:debugging`
3. Нажмите "Этот Firefox"
4. Нажмите "Загрузить временное дополнение"
5. Выберите скачанный zip-файл

### Поддерживаемые браузеры

- Chromium-браузеры с Manifest V3: Google Chrome, Microsoft Edge, Opera, Vivaldi. Автоматически проверен Chromium 153.
- Mozilla Firefox с Manifest V2. Автоматически проверен Firefox 155.

Минимальные версии браузеров отдельно не проверялись.

## Использование

1. Откройте один из поддерживаемых сайтов.
2. Нажмите на иконку расширения.
3. Переключитесь на другой сайт или скопируйте ссылку.
4. В попапе или через ⚙ откройте **Настройки**: предпочитаемые сайты ТС и A2, fallback при ошибке, видимость кнопок.

### Предпочитаемый хост (перехват)

Если выбран, например, `rating.pecheny.ru`, любой переход на `rating.chgk.info`, `.me` или `.kz` сразу откроется на `.ru` с тем же путём. По умолчанию перехват **выключен**. Если сайт уводит на `rating.chgk.info/login`, расширение открывает `/login` на предпочитаемом хосте (или на том зеркале, с которого пришли, если перехват выключен).

Для A2 в настройках есть отдельный раздел **Перехват A2**: выберите a2.pecheny.me, a2.pecheny.kz или a2.pecheny.ru. По умолчанию он выключен. Любые страницы, включая релизы и методику, открываются на выбранном зеркале с прежними параметрами и якорем. Кнопка другого зеркала в попапе открывает его напрямую, сохраняя настройку.

Поддержка зеркал и независимый перехват A2 добавлены в версии 1.1.1.

### Fallback при ошибке загрузки

Если перехват выключен и TS-сайт не загрузился (DNS, «сайт недоступен»), в попапе появится предложение перейти на другое зеркало (из включённых в настройках видимости переключения). Не срабатывает при HTTP-ошибках с телом страницы или «бесконечной» загрузке.

## Оформление расширения

Попап и настройки используют Noto Sans из темы ТС. Шрифт включён в расширение и работает без интернета.

На Турнирном сайте попап автоматически использует тему открытой вкладки: Classic, Oldschool, Catppuccin или тему для дальтоников, светлую или тёмную. Для всех сайтов рейтинга используется оформление rating.chgk.gg: на rating.chgk.gg режим берётся с сайта, на остальных — из настроек браузера/ОС.

В настройках можно независимо выбрать режим ТС, тему ТС, повышенную контрастность ТС и режим рейтингов. Ручной выбор применяется к попапу и странице настроек. Страница настроек следует активному или последнему выбранному поддерживаемому сайту своего окна; если таких вкладок нет, использует параметры ТС. Изменения оформления видны без перезагрузки. Classic, Oldschool, Catppuccin и тема для дальтоников доступны в светлом и тёмном вариантах, с обычной или повышенной контрастностью. Автоматическая контрастность следует настройке ТС; её также можно включить или выключить вручную. Если данные страницы недоступны, автоматические настройки используют резервную тему; ручной выбор сохраняется.

## Разрешения

| Разрешение | Обоснование |
|------------|-------------|
| `activeTab` | Доступ к активной вкладке при клике на иконку: URL, переключение. |
| `tabs` | URL в попапе, обновление вкладки, иконка расширения. |
| `storage` | Локальные настройки зеркала, кнопок, оформления и предложения зеркал при ошибке; временное состояние вкладок. |
| `declarativeNetRequest` (Chromium) | Перехват навигации на предпочитаемый ТС-хост. |
| `webRequest` + `webRequestBlocking` (Firefox) | То же для Firefox. |
| `webNavigation` | Обнаружение ошибки и успешной загрузки, обработка переходов входа/выхода на ТС. |
| `host_permissions` (9 доменов ТС и рейтингов) | Работа только на этих сайтах. |

Телеметрии и внешней загрузки шрифтов нет. На устройстве хранятся настройки, а также служебное состояние вкладок: URL ошибки загрузки и последний ТС-хост. Для временного состояния используется session storage, при его отсутствии — local.

## Безопасность

- Не собирает пользовательский контент и не передаёт его третьим лицам
- Весь код открыт для проверки

## Обработка пользовательских данных

Расширение не сохраняет содержимое страниц. На устройстве хранятся настройки и служебное состояние вкладок, описанное в разделе разрешений. Запись fallback удаляется при успешном переходе или закрытии вкладки; срок её актуальности — пять минут, проверяется при чтении.
