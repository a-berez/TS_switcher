# История изменений TS_switcher

Все версии в кратком описании для пользователей. Последний релиз — в [README](README.md#история-изменений), технические подробности — в [full_changelog.md](full_changelog.md). Описания выпусков на GitHub берутся из этого файла.

Каждая версия описывается целиком относительно предыдущего стабильного релиза. Промежуточные beta-сборки входят в общий раздел своей версии.

### Версия 1.0.0

Готовится к выпуску. Изменения по сравнению с версией 0.3.5:

- Добавлены зеркало `rating.pecheny.ru` и рейтинги `rating.chgk.fun`, `chgk.quest`, `elo-chgk.uk`. Теперь расширение поддерживает восемь сайтов.
- Можно выбрать любимое зеркало Турнирного сайта: ссылки на другие зеркала будут открываться на нём. При этом можно вручную перейти на другое зеркало кнопкой расширения.
- Если Турнирный сайт недоступен, расширение предлагает открыть ту же страницу на другом зеркале.
- Появились настройки: можно скрыть ненужные кнопки перехода и копирования, выбрать зеркало и включить предложение другого зеркала при ошибке загрузки. Из настроек также можно открыть страницу входа на каждом зеркале.
- Копировать ссылки теперь можно на любой из поддерживаемых сайтов, включая текущий. Кнопки разделены на два ряда: Турнирный сайт и зеркала сверху, рейтинги снизу.
- При переходе между зеркалами и копировании ссылок сохраняется ссылка на конкретное место страницы, например на отдельный раздел.

### Версия 0.3.1

**Поддержка пути `/players/` на Турнирном сайте**
- Исправлено: переключение на сайт Рейтинга теперь появляется на страницах игроков (`/players/<id>`)
- Исправлено: страницы игроков корректно переводятся в `/b/player/<id>/` на сайте Рейтинга (раньше ошибочно переходили на `/b/team/<id>/`)

**Улучшено копирование ссылок**
- Исправлено: «Копировать ссылку оригинала» на страницах сайта Рейтинга теперь конвертирует путь (например `/b/player/123/` → `/players/123`), а не только заменяет домен
- Добавлены кнопки «Копировать ссылку зеркала .me» и «Копировать ссылку зеркала .kz» в одну строку под основной кнопкой

### Версия 0.2.1

**Улучшен интерфейс**
