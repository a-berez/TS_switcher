Дата проверки: 2026-10-04. Первичный аудит выполнен на `60121d6`; затем по указанию владельца подготовлена стабильная версия `1.0.0`.

**Вывод: локальные пакеты стабильной версии 1.0.0 подготовлены; публикация отложена пользователем после сбоев соединения.** Владелец подтвердил возможность распространения графики, сообщил, что расширение работает, и поручил публикацию на GitHub. Подробная ручная матрица не зафиксирована; это ограничение подтверждения, а не оставленный владельцем запрет на выпуск.

## Пакеты стабильной версии

Первичный аудит обнаружил устаревшие локальные ZIP beta.8. По последующему указанию владельца подготовлены стабильные архивы `1.0.0`; версии обоих manifest также `1.0.0`. Из обеих лицензий удалён раздел об иконках, прочие уведомления сохранены. Лицензии в корне, src и пакетах совпадают.

Архивы без версии побайтово совпадают с соответствующими архивами 1.0.0. Хеши относятся к локальной сборке: повторная сборка в GitHub Actions меняет время ZIP-записей и может отличаться побайтово при одинаковом содержимом.

## Решения владельца

- Распространение графики разрешено; раздел об иконках удалён из лицензий по прямому указанию. Новое юридическое заключение в рамках задачи не составлялось.
- Пользователь сообщил: «Кажется, работает». Независимую проверку всех ручных сценариев это не заменяет; пользователь поручил выпуск с этим уровнем подтверждения.
- Публикуется полноценный GitHub Release `1.0.0`, не beta. Настройка beta-публикации для этой задачи не требуется.
- Техническая версия должна быть ровно `1.0.0`: beta.8 с номером `1.0.0.8` использовалась только локально у владельца. Автоматическое обновление с неё не требуется; для локального перехода нужна переустановка.

## Публикация и границы проверки

Публикация разрешена только на GitHub. Отправка тега `v1.0.0` запускает `release.yml`: проверки, сборку и GitHub Release с четырьмя ZIP. `permissions: contents: write` задано явно. Сообщение подготовительного коммита не должно иметь вид `vX.Y.Z`, чтобы не запустить отдельный магазинный workflow при обновлении main.

Магазинные доступы и текущие версии магазинов не подтверждены; публикация туда не запрошена. Сохранённое `continue-on-error` шага AMO не относится к выбранному GitHub-only маршруту. Минимальные версии браузеров, системный clipboard, живые сессии и магазинный валидатор независимо не проверялись.

При проверке соединения GitHub неоднократно отвечает TLS-ошибкой/тайм-аутом (git и gh). Команды push и создания релиза не выполнялись. Пользователь поручил завершить локальную подготовку и подготовить коммит; отправка отложена. Повторный Chromium-прогон также дважды остановился на `/logout` с ERR_TIMED_OUT, без нарушенных ожиданий до тайм-аута. Совпадение по времени не доказывает общую причину. Firefox 39/39 на стабильной версии пройден повторно.

При возобновлении публикации проверить соединение и Chromium-прогон, затем отправить исходники и тег на GitHub, дождаться выпуска и проверить вложения. Текущая передача — [handoff.md](handoff.md).
