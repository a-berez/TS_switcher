# Handoff: новые палитры ТС
Date: 2026-10-02

## Goal

После получения обновлённого CSS подключить реальные светлую/тёмную темы для дальтоников и автоматическую повышенную контрастность из настроек самого ТС.

## Done

Базовая адаптация попапа и страницы настроек реализована: шесть тем ТС, две рейтингов, поток темы активной вкладки, четыре независимые настройки. Ручной повышенный контраст работает. Регрессии и оба настоящих браузера проверены; результаты — status.md. Выпуск не выполнялся.

## Not done

Обновлённый CSS ещё не предоставлен. В options тема для дальтоников видна как недоступный пункт, Theme.families.colorblind=false. Это технический резерв, не утверждение о будущем имени темы на сайте. Автоматическая контрастность возвращает normal, пока неизвестен реальный признак в DOM; предпочитаемую контрастность ОС для этого не использовать.

## Invariants

Семейство, светлый/тёмный режим и контрастность ТС независимы. Ручной выбор выше сайта. На gg auto следует контексту страницы, другие рейтинги — контексту попапа. Settings пишет только background; тема вкладки не хранится. Кнопки не пересоздаются при смене темы. Новых разрешений нет.

## Where to look

- themes.css и tools/generate-themes.py: источник и генерация палитр. Текущий генератор ожидает шесть палитр ТС; при добавлении новых обновить проверку и селекторы осмысленно.
- src/theme.js: реестр семейств, readPage (место подключения реального признака контрастности), resolve (приоритеты).
- src/content.js: attributeFilter должен включить фактический атрибут контрастности, когда он станет известен.
- src/settings.js и src/options.html: разрешить новое семейство и включить пункт после добавления обеих палитр.
- src/theme-overrides.css: общий для попапа и options независимый контрастный слой. Если сайт предоставит собственные контрастные токены, заменить этот слой с учётом приоритетов CSS.
- docs/popup-themes-plan.md: исходные исследования и источники цветов gg.

## Verify

Команды в tests/README.md. Добавить новые темы в audit-themes и оба браузерных набора, проверить настоящие цвета (не только атрибуты), normal/more и их независимость от light/dark. В Chromium есть снимки восьми палитр и ручного контраста; toolbar popup и живые настройки аккаунта требуют ручной проверки.
