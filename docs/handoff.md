Date: 2026-10-04
Left by: Codex

## Goal
Локальная подготовка `1.0.0` завершена. После сбоев соединения пользователь попросил подготовить коммит; отправка на GitHub отложена. При возобновлении — опубликовать стабильный GitHub Release `v1.0.0` с архивами Chromium и Firefox.

## Done
Версия сборки и обоих manifest — `1.0.0`. Локальные ZIP собраны и сверены с исходниками. Проверки логики/сборки проходят; Firefox 39/39 повторно пройден. Полный Chromium 39/39 проходил до смены версии в этот же день, повторный прогон дважды остановился на `/logout` с ERR_TIMED_OUT (exit 2). Раздел об иконках удалён из обеих лицензий по указанию владельца; владелец подтвердил возможность распространения и сообщил, что расширение работает.

## Not done
GitHub git/API неоднократно недоступны из-за TLS-ошибки/тайм-аута. Push и создание релиза не выполнялись. Пользователь отложил публикацию. Для будущего выпуска остаются отправка исходников/тега и проверка GitHub Release, а также выяснение причины тайм-аута повторного Chromium-прогона. Магазины не входят в текущую задачу.

## Invariants
Использовать ровно `1.0.0`, без четвёртого компонента: beta.8 тестировалась только локально. Не запускать магазинный workflow сообщением коммита `v1.0.0` в main. Для выпуска на GitHub использовать тег.
