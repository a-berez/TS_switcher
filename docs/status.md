Совместимость обновления с локальной beta не требуется; защита сборщика от понижения относительно исходных manifest сохранена.

Проверки 2026-10-04: 772 ожидания UI/URL/settings, 62 ожидания политики тем, 21 сценарий background, 39 общих проверок Chromium 153, 287 проверок тем/шрифтов, три проверки перезапуска worker и 39 проверок Firefox 155. После подготовки stable повторно пройдены проверки логики, тем, изолированной сборки/workflows, все 39 проверок Firefox и все 39 проверок Chromium. Предыдущий Chromium-прогон останавливался на `/logout` с `ERR_TIMED_OUT`; после восстановления соединения полный повторный запуск прошёл без ошибок консоли. Оба стабильных ZIP содержат по 30 файлов и побайтово сверены с входами сборщика. Подробности — [publication-readiness-2026-10-04.md](publication-readiness-2026-10-04.md).

В workflow исправлено создание каталога для XPI; GitHub Release перенесён перед магазинными шагами, чтобы их сбой не пропускал выпуск на GitHub. История изменений разделена на три уровня: в `../README.md` — последний релиз, в `../CHANGELOG.md` — все релизы понятным пользователю языком, в `../full_changelog.md` — все релизы с техническими подробностями. ## Holes

- Пользователь считает ручную проверку успешной; независимая проверка живой авторизации, toolbar popup/clipboard и минимальных версий браузеров не выполнялась.
- Fallback работает по сетевым ошибкам, не по HTTP-ответам 4xx/5xx или зависшей загрузке.
- Firefox не меняет иконку расширения по хосту (сохранённое ограничение).
- Локальная beta.8 имеет больший числовой номер; для перехода с неё на публичную 1.0.0 нужна переустановка. Для публичной предыдущей версии 0.3.5 номер повышается.
