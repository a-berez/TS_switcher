# Status
Date: 2026-10-01

## Now

Подготовлена `1.0.0-beta.8`, оба manifest — `1.0.0.8`. Исправлены найденные ошибки перехвата, auth redirect/grace, fallback, хранения настроек, URL и выпуска. Пользователь выбрал beta.8; схема будущего stable не менялась. Исходники и регрессионные тесты подготовлены для beta.8; публикация не выполнялась.

Регрессии зелёные: 552 ожидания UI/URL/settings, 21 сценарий background, 36 проверок настоящего Chromium 153 и три проверки перезапуска worker, 16 проверок настоящего Firefox 155. Изолированная сборка и ветви CI также проходят. Команды и ограничения — `../tests/README.md`.

## In progress

Открытых исправлений по выполненному аудиту нет. Первичные находки и их закрытие — `audit-2026-10-01.md`; актуальная архитектура — `architecture.md`.

## Next

Перед публикацией установить beta.8 и пройти ручной вход/выход на настоящих сайтах; текущие браузерные проверки используют контролируемые ответы.

## Holes

- Реальные пользовательские сессии сайтов, toolbar popup/clipboard и минимальные версии браузеров не проверялись.
- Fallback работает по сетевым ошибкам, не по HTTP-ответам 4xx/5xx или зависшей загрузке.
- Firefox не меняет иконку расширения по хосту (сохранённое ограничение).
- Будущий stable должен иметь числовую версию выше beta.8; сборщик отвергает downgrade вместо создания непригодного обновления.
