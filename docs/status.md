# Status
Date: 2026-10-04

## Now

Подготовлен стабильный релиз `1.0.0`: оба manifest и версия сборки — `1.0.0`. Владелец уточнил 2026-10-04, что beta.8 (`1.0.0.8`) тестировалась только локально, и явно выбрал чистый технический номер `1.0.0`. Совместимость обновления с локальной beta не требуется; защита сборщика от понижения относительно исходных manifest сохранена.

LICENSE и src/LICENSE совпадают. По прямому указанию владельца раздел об иконках и упоминание Emoji Kitchen удалены из лицензий; владелец подтвердил возможность распространения. Полные OFL/MIT-уведомления шрифта и палитр сохранены. Пользователь сообщил, что расширение, по его оценке, работает; подробная матрица ручных сценариев отдельно не зафиксирована.

Проверки 2026-10-04: 772 ожидания UI/URL/settings, 62 ожидания политики тем, 21 сценарий background, 39 общих проверок Chromium 153, 287 проверок тем/шрифтов, три проверки перезапуска worker и 39 проверок Firefox 155. После подготовки stable повторно проходят проверки логики, тем, изолированной сборки/workflows и все 39 проверок Firefox. Повторный Chromium-прогон дважды останавливается на навигации `/logout` с `ERR_TIMED_OUT` (exit 2), до этого нарушенных ожиданий нет; полный прогон 39/39 проходил ранее в этот же день. Одновременно недоступны TLS-соединения с GitHub; причина сбоя Chromium отдельно не установлена. Оба стабильных ZIP содержат по 30 файлов и побайтово сверены с входами сборщика. Подробности — [publication-readiness-2026-10-04.md](publication-readiness-2026-10-04.md).

Локальная подготовка `1.0.0` завершена. После сбоев соединения пользователь поручил подготовить коммит и отложил отправку на GitHub. Выпуск в магазины не запрошен. GitHub workflow получил явное право `contents: write`; будущая публикация выполняется через тег, без запуска магазинного workflow.

История изменений разделена на три уровня: в `../README.md` — последний релиз, в `../CHANGELOG.md` — все релизы понятным пользователю языком, в `../full_changelog.md` — все релизы с техническими подробностями. Оба workflow берут описания выпусков из CHANGELOG. Во всех трёх документах версия 1.0.0 описана целиком относительно стабильной 0.3.5, без промежуточных разделов beta. Описания beta-выпусков используют общий раздел 1.0.0.

Реализованы 16 сочетаний палитр ТС (четыре семейства × два режима × два уровня контрастности) и две палитры gg для рейтингов, получение темы активной TS/gg-вкладки, независимые настройки режима ТС, семейства ТС, контрастности ТС и режима рейтингов. Страница options также следует настройкам и контексту сайта в своём окне, включая автоматическое обновление и повышенный контраст. В попапе и options подключён Noto Sans из themes.css, включая кнопки и select; файл шрифта и лицензия локально включены в расширение. Версии manifest — 1.0.0. Источники палитр — [popup-themes-plan.md](popup-themes-plan.md), текущее поведение — [architecture.md](architecture.md).

Исправлено распознавание `/tournaments/:id` на всех четырёх ТС: теперь доступны переключение и копирование на рейтинги. Проверены маршрут `/tournaments/13362`, подпути, параметры, сохранение пути между зеркалами и настоящий переход в Chromium на контролируемых ответах.

## Holes

- Пользователь считает ручную проверку успешной; независимая проверка живой авторизации, toolbar popup/clipboard и минимальных версий браузеров не выполнялась.
- Fallback работает по сетевым ошибкам, не по HTTP-ответам 4xx/5xx или зависшей загрузке.
- Firefox не меняет иконку расширения по хосту (сохранённое ограничение).
- Локальная beta.8 имеет больший числовой номер; для перехода с неё на публичную 1.0.0 нужна переустановка. Для публичной предыдущей версии 0.3.5 номер повышается.
